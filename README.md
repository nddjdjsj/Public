# PsycheEngine

可直接安装到 SillyTavern 的动态人格扩展。以五大人格及 30 个 IPIP-NEO 分面建立稳定倾向，用事件日志驱动 PAD 情绪、分对象五维关系、记忆和行为建议，再向当前模型注入有预算的状态提示词。

默认使用本地保守规则，不需要独立后端、数据库、GPU 或额外模型服务。人格与角色绑定，情绪/关系/记忆与聊天绑定，全局选项单独保存。普通对话不会改写原始测评分。所有情绪、关系和决策权重都是可解释的工程模拟，并非心理诊断、意识或人格复制。

## 安装

参考兼容目标是 **SillyTavern 1.19.0 release**，核对源码提交 `06bde939fb1e9c4c8d8641d810f0a916b5bce127`。开发环境没有连接正在运行的用户 SillyTavern；真实宿主验收见 [验收清单](docs/ACCEPTANCE.md)。

可在 SillyTavern 的“扩展 → 安装扩展”中输入以下仓库地址：

```text
https://github.com/nddjdjsj/Public
```

或下载 [PsycheEngine-1.0.0.zip](https://github.com/nddjdjsj/Public/raw/refs/heads/main/downloads/PsycheEngine-1.0.0.zip) 和 [SHA-256 校验值](https://github.com/nddjdjsj/Public/raw/refs/heads/main/downloads/PsycheEngine-1.0.0.zip.sha256)，手动安装：

1. 备份当前角色卡和聊天。解压交付 ZIP，保留完整的 `SillyTavern-PsycheEngine` 文件夹。
2. 将该文件夹放到当前 SillyTavern 用户的扩展目录：`<SillyTavern>/data/<用户>/extensions/SillyTavern-PsycheEngine/`。默认用户通常为 `default-user`。使用自定义 dataRoot 时，以实际数据目录为准。也可由服务器管理员安装到 `<SillyTavern>/public/scripts/extensions/third-party/SillyTavern-PsycheEngine/`。
3. 检查目标文件夹内直接包含 `manifest.json` 和 `index.js`，避免多套一层目录。两个位置只安装一份。
4. 刷新 SillyTavern 页面，在扩展设置中找到 **PsycheEngine · 动态人格**。选择一位角色并打开单人聊天。
5. 在“设置”检查“启用 PsycheEngine”“动态 Prompt 注入”，点击“应用设置”。在“当前环境兼容能力”查看宿主 API 能力与降级说明。

扩展使用原生 JavaScript ESM，可直接运行，无需构建或在 SillyTavern 服务器安装 npm 依赖。ZIP 手动安装不需要 GitHub 账号。仓库名称为 `Public`，扩展名称为 `PsycheEngine`；安装目录可由 SillyTavern 管理，不依赖硬编码的文件夹名。

更新时先导出备份，再替换该扩展文件夹并刷新；不要同时保留旧目录和新目录。卸载时先在设置中停用、导出需要的数据，再删除扩展目录。角色卡和聊天正文仍可正常使用；要同时清除本扩展数据，请先使用面板的重置/删除功能。

## 开始使用

“人格”分区可调整 O/C/E/A/N 五个滑块，展开 30 分面设置细节；值为内部 0–1 归一化，**不是人群百分位**。载入高外向性、高内向性、高宜人性、高神经质或混合预设后，点击“保存到当前角色”。这些预设与随机人格都是模拟数据。原始分数、量表版本和质量标记单独显示；手动调整内部值不会将原始测评伪装成新结果。

“测试结果导入与导出”支持选择文件或粘贴 JSON/CSV。导入按钮会校验后保存到当前角色。最小 JSON 示例：

```json
{
  "version": 1,
  "source": "manual",
  "baseline": { "O": 0.75, "C": 0.4, "E": 0.25, "A": 0.8, "N": 0.65 },
  "facets": { "N1": 0.7, "A1": 0.65 },
  "scoring": "internal-normalization"
}
```

缺失分面会回填所属大五维度并标记。已完成合法计分的 IPIP-NEO-120 原始加总也可导入：

```csv
trait,raw,normalized
E,96,0.75
A,,0.80
N1,16,
```

域原始加总范围 24–120，分面 4–20；原始值和内部值至少填写一项。CSV 第一行必须是上述列名。完整格式和限制见 [提取与导入说明](docs/EXTRACTION.md)，五份完整模拟配置在 [examples](examples/) 中。扩展不采集私人测试结果，也不从未知题号猜测反向计分。

## 事件、情绪与关系

规则模式只自动接受少量明确、低歧义的完整语句。例如发送 `我刚才帮你搬好了箱子。`，等待角色完成回复后检查情绪、关系和记忆。假设、引语、回忆、关键词堆砌和角色自己生成的“回忆”不会作为可信自动事实。更多可识别中英文语句及模式边界见 [提取说明](docs/EXTRACTION.md)。复杂剧情可在“记忆 → 手动确认剧情事件”中记录已发生的事实。

违约、欺骗、侵犯边界、忽视和其他高影响候选会等待人工确认；在“记忆”分区确认或拒绝。确认后才应用对应心理影响。友好事件不会迅速将关系拉满，道歉也不会抹去所有冲突。关系面板按对象分别显示信任、亲密、尊重、依恋和冲突，并可查看变化原因。

“情绪”展示 PAD 三轴、标签、强度和历史。默认恢复依据剧情时间；在“当前累计剧情分钟”输入新的累计值并推进，现实等待不会冒充角色经历的时间。设置可选择有效轮次或仅事件恢复，并调整速度、敏感度。可以手动修正 PAD 或恢复到人格情绪基线；这些操作由可撤销事件记录。

长期人格适应默认关闭。开启后可在“人格 → 缓慢人格适应”选择维度、输入上限内的偏移和修改原因，并从历史撤销；不会根据几句聊天自动改写角色。当前图形面板没有自动人格训练器或任务规划器，扩展点与原理见 [心理学来源及算法](docs/PSYCHOLOGY.md)。

## 记忆和 Prompt

“记忆”支持搜索、查看稳定来源 ID、修正摘要、撤销事件及影响、确认高影响事件和从日志重建。摘要修正不会自动改变事件类别；发现原事实有误时，撤销后添加正确事件。删除或编辑来源消息后，相关旧效果会由生命周期核对撤回；Swipe 和重新生成使用来源修订与确定事件 ID 去重。

“调试”可预览最终状态 Prompt。默认预算为 300 tokens，可选择中文或英文，并分别关闭人格、情绪、关系、记忆、行为片段。提示词使用自然语言倾向，不暴露内部数值，不把自由文本记忆和聊天证据当作高信任指令。宿主 tokenizer 不可用时采用 UTF-8 字节数保守限额，中文内容可能更短。

调试日志默认关闭并有数量限制；开启后可查看事件提取、心理评价、状态差异、提交/回滚和错误。请谨慎分享包含私人剧情的调试内容。群聊采用保守策略，自动注入停用，避免将一个角色的私人状态应用给其他角色。

## 可选模型分析与隐私

若规则模式不能覆盖你的叙述，可在设置中切换到“当前模型”，勾选聊天内容发送说明并应用。该模式会将选中的来源消息、允许事件类型与参与方 ID 发到 **SillyTavern 当前配置的模型服务**；是否收费由你的连接决定。关闭时没有额外事件分析请求，日常角色生成仍使用原有 SillyTavern 连接。

模型结果严格校验，包含置信度、范围、证据逐字匹配、人物、事实类型和去重检查；失败会回退规则。存在超时、取消和调用次数限制。当前 `generateRaw` 没有可传入的 AbortSignal，取消会丢弃结果，底层模型网络请求仍可能完成。模型分析不能证明故事真实，重要事件仍应查看来源并确认。

本扩展不内置遥测或独立上传服务；所有本地数据仍由 SillyTavern 自己的服务器、用户目录与备份策略管理。不要把自托管远程服务器上的保存误认为仅保存在浏览器本机。

## 备份、重置和恢复

“设置 → 聊天数据备份”导出当前范围的 JSON，包含当前角色人格、聊天事件及相关配置；文件可能含私人剧情。备份导入仅恢复当前角色的聊天事件，并撤销已不存在的消息来源；不会静默替换角色卡人格或全局选项。人格请使用人格导入，选项请在设置中分别调整。导入前先备份原数据。损坏或不支持版本的数据会隔离并报告，避免阻断聊天；在确认后导入有效备份或重置。

“重置当前聊天”需勾选确认，清除本扩展的当前聊天动态状态，保留角色人格和聊天正文。人格可载入中性模拟配置并保存，或导回原人格文件。禁用扩展会清空注入并移除运行中的聊天监听；重新启用时重新读取当前范围。

## 开发与验证

使用 Node.js 20 或更新版本，在扩展根目录执行：

```sh
npm test
```

测试使用 Node 原生测试框架，无安装依赖，也可直接执行 `node --test`。`tests/core.test.js` 覆盖纯算法与事件存储；`tests/extraction.test.js` 覆盖输入边界、导入、限额和取消；`tests/prompt.test.js` 覆盖预算、语言与注入边界；`tests/statistics.test.js` 覆盖固定种子下的策略分布；`tests/integration.test.js` 与 `tests/review.test.js` 使用模拟宿主测试 Adapter、异步竞争和隐私隔离。模拟宿主通过不代表真实 SillyTavern 页面已验收。

执行 `npm run build` 检查所有可安装模块；PowerShell 执行 `./scripts/package.ps1` 生成并逐文件核对 ZIP。交付实测结果见 [VALIDATION.md](docs/VALIDATION.md)。浏览器 UI 夹具及尚未执行的检查见 [BROWSER-UI.md](docs/BROWSER-UI.md)。

架构为 `SillyTavern Adapter → 提取 → 评价/人格/情绪/关系/记忆/行为 → StateManager → Prompt → 最终有效消息提交`。核心不依赖 DOM 或 SillyTavern；专属接口集中于 Adapter。事件日志是重建依据，快照是有界缓存。普通追加增量计算，删除/修订/纠错时重建；达到事件容量上限会要求导出或另开聊天，不静默丢失历史。详细数据结构和兼容核对参见 `docs/` 以及核心模块导出。

尚未在用户的真实 SillyTavern、实际模型连接、移动端主题和长历史生产聊天中执行验收。浏览器缓存、其他扩展、分支/导入方式及未来 API 变化可能影响生命周期，必须完成 [人工验收清单](docs/ACCEPTANCE.md) 后再用于重要长期聊天。本软件沿用目标仓库原有的 [Apache 2.0 许可证](LICENSE)。
