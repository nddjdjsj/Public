# 浏览器设置面板检查

`tests/browser-smoke.html` 是真实浏览器中运行的独立 UI 冒烟夹具。它使用模拟控制器，不连接 SillyTavern，也不会调用模型。它不能替代真实 SillyTavern 端到端验收。

本次交付中，这组浏览器断言**尚未执行**。初次启动无窗口 Chrome 时，系统执行审批一直未完成，随后该工具调用被中断；后续重试又在执行前收到工具拒绝，Chrome 未启动，也未产生浏览器结果文件。两次本地 HTTP 夹具服务器均已停止。没有浏览器通过或失败结果，也未生成截图。`ui/panel.js` 已实际执行 `node --check` 语法检查。

复现方法：

1. 在扩展项目目录运行 `node tests/browser-server.mjs`。
2. 在浏览器打开 `http://127.0.0.1:8137/tests/browser-smoke.html`。
3. 页面顶部报告 `PASS` 或 `FAIL`，并列出实际执行的断言。
4. 使用 Ctrl-C 停止夹具服务器。

夹具覆盖六个分区、5 + 30 个人格滑块、未保存编辑保留、人格导入及错误提示、LLM 数据发送说明的显式同意、缓慢人格适应的启用限制与撤销历史、PAD SVG、分对象关系、待确认高影响事件、记忆搜索和修正、XSS 文字渲染、Prompt 预览、备份、重置确认以及销毁监听器。

这些断言目前只是可执行的检查定义。真实 SillyTavern 中的主题兼容、扩展抽屉布局、持久化与聊天生命周期仍须按照 README 的手工验收步骤验证。
