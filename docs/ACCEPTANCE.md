# 验证范围与真实宿主验收

本项目区分三类验证：

1. **纯模块测试**：Node 中执行人格、情绪、关系、记忆、StateManager、导入、提取和 Prompt 模块，不使用真实 DOM、SillyTavern 或模型。
2. **模拟宿主集成测试**：`tests/integration.test.js` 与 `tests/review.test.js` 使用模拟 context/event bus，运行实际 Adapter 连接逻辑及异步/隐私回归；不代表真实聊天服务器和生成服务。
3. **真实宿主人工验收**：需要安装到实际 SillyTavern，检查真实生成、持久化、UI、Swipe、分支和模型连接。本开发环境没有接入用户正在运行的 SillyTavern，此类别**未执行，不能记为通过**。

参考源码：SillyTavern 1.19.0 release，提交 `06bde939fb1e9c4c8d8641d810f0a916b5bce127`。未来版本及第三方分支需要重新核对 API。终端执行结果是自动化通过数量的依据，禁止根据本映射表推算真实宿主验收通过。

```sh
node --test
```

## 已知限制与可接受降级

- 群聊不自动注入私人状态；第一版主要针对单人角色聊天。
- 已锁定 `force_avatar` 的注册 Persona 按稳定头像标记区分；没有该标记的旧消息只能回退显示名，旧历史中同名不同 Persona 可能无法可靠区分。
- 规则模式覆盖刻意有限，不理解所有故事、人物指代、否定、引语和假设变体；不确定时不修改状态。
- 自动事件只采用用户的明确来源文本。角色生成的叙述不自动成为真实聊天历史事实。
- 模型模式的语义抽取不可完全验证，必须保留来源和高影响确认。`generateRaw` 无 AbortSignal 参数；超时/取消会丢弃结果，底层网络可能继续完成。
- 编译 Prompt 使用安全事件类别模板；人工摘要可以搜索和显示，但不会逐字进入高信任 Prompt。改摘要不等于改变事实类型。
- tokenizer 不可用时使用 UTF-8 字节保守预算，尤其中文 Prompt 会缩短；这不代表已实测所有 tokenizer。
- 人格数据不含常模百分位；现有导入支持计分后结果，不提供题目作答或未经验证的中文量表。
- 适应功能仅处理显式确认、有限速度、有原因的偏移；不会自动训练人格。行为目标与场景约束存在核心扩展接口，UI 未提供完整任务规划。
- 编辑、撤销、来源变更和导入可能需要重建有效事件日志，复杂度随有效事件数增长。生产规模延迟及与其他扩展的冲突未经过实机压力测试。
- 官方 `saveMetadata()` 最终保存宿主当前聊天，没有独立的聊天 scope 参数；在宿主等待其他保存期间快速切换聊天的持久化次序，需在实际服务器复核。本扩展会阻止跨范围状态应用，但不声称控制宿主内部的保存调度。
- 快照不作为任意导入状态的可信依据；事件日志达到容量后需备份或新聊天。文件被外部工具破坏时可能只能从备份恢复。
